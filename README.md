# Astronia IDE

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Framework: Electron](https://img.shields.io/badge/Framework-Electron-47848F?logo=electron&logoColor=white)](https://www.electronjs.org/)
[![UI: Shadcn](https://img.shields.io/badge/UI-Shadcn-000000?logo=shadcnui&logoColor=white)](https://ui.shadcn.com/)

**Astronia** is a professional-grade, maker-first desktop development environment specifically engineered for the **Astronics Cera** ecosystem and compatible hardware. 

Designed to bridge the gap between visual logic and professional code, Astronia offers a seamless, immersive experience for both beginners and veteran engineers.

---

## 🚀 Key Features

- **Dual-Engine Editing:** Toggle between a high-performance **Monaco Editor** and a drag-and-drop **Google Blockly** canvas.
- **Contextual AI (Astra):** An integrated Gemini-powered co-pilot designed to debug hardware errors and optimize firmware in real-time.
- **Hardware First:** Native integration with Astronics Cera, Arduino, and ESP32 boards with one-click verify-and-upload pipelines.
- **Modular Design:** Built on the "Astronia Night" design system—a minimalist, technical aesthetic optimized for long-term focus.
- **Community Integrated:** Earn XP as you build and sync your achievements with the Astronians platform.

## 🛠 Tech Stack

- **Shell:** Electron
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Framer Motion
- **Core Engines:** Monaco Editor, Google Blockly, Firebase Auth

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or pnpm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Aryan-Ghadge/Astronia.git
   cd Astronia/astronia
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Launch the IDE in development mode:
   ```bash
   npm run dev
   ```
